# 安卓电视与遥控器

APK：`release/android-tv/yingji-tv-0.1.18.apk`。应用名「映集」，包名 `app.yingji.tv`，支持 Android 9 或更新版本，需要 Android System WebView 66 或更新版本。电视桌面提供启动入口，应用固定横屏、全屏，默认电视字号，可切换界面字号模式。此包用于侧载测试，以项目本机保留的开发证书签名，未提交应用商店。

## 安装

0.1.18（versionCode19）手机顶栏对齐桌面六个主栏目和二级分类，搜索通过图标打开居中卡片，历史区分B站与本机记录，设置按组切换无需滚动。保留首页遥控器气泡、收藏与队列管理、电视登录二维码快捷入口及同分辨率画质策略。沿用原签名并关闭调试，支持覆盖升级；画质设置不主动打断当前视频。此包完成前后端构建、原生编译和包完整性校验，尚未在实体电视验收，不代表4K解码或弹幕卡顿问题已修复。

将 APK 拷贝到电视，用电视文件管理器打开并允许该来源安装应用。也可以在已连接、已授权调试的目标电视上执行：

```sh
adb -s <电视序列号> install -r release/android-tv/yingji-tv-0.1.18.apk
```

保留签名密钥后重新构建可覆盖升级；更换签名时不能直接覆盖。卸载会清除本机历史、队列、设置和授权，因此不要为了升级先卸载。首次使用没有预装账号或虚构推荐；B 站仍需本人扫码授权。

若启动失败，原生错误页直接显示型号、实际 Android/API 与 WebView 版本，并可用方向、中键重试或退出。其他初始化错误显示阶段和异常类型，不展示原始异常内容。用户照片已确认 L55M7-EA / MiTVOS 2.6.1385 实际为 MiTV-ASTP0、Android 9/API28、WebView 66.0.3359.158。0.1.2 补齐语法、标准 API、字素删除、inert/尺寸观察及旧 CSS 布局和焦点，原生桥脚本同步采用旧语法；相同内核模拟器通过后才将最低版本降至66。无需更换电视系统组件，实体电视仍待安装反馈。

## 手机网页遥控

手机遥控随应用自动开启。在电视的「设置 → 手机遥控」查看二维码，用同一局域网的手机扫码访问。源码中的手机控制台提供封面/标题浏览、独立搜索、选片、播放进度/倍速/画质/选集、观看与弹幕设置，以及普通 B 站视频的相关推荐；方向键、滑动区与自定义快捷键保留在顶部按键卡片。安卓链接能力仍限于已有 B 站解析与媒体直链，不增加第三方网页检测。

不再提供关闭开关，启动及网络未就绪时自动重试，地址变化会更新二维码。手机记住同源配对，关闭标签页后可重访地址并重连；401或主动忘记时清除。电视切至后台时不执行控制命令，返回沿用原连接；退出或系统结束进程后，重新启动需扫码。服务使用 HTTP，仅用于可信局域网，不映射到公网；手机只取得列表展示信息和有限操作句柄，不取得账号凭据、本地路径、媒体地址或任意原生桥。无法连接时检查同一网络、路由器客户端隔离及多网卡所选地址。实体电视及手机 Wi-Fi 可达性仍需设备实测。

## 七键操作

| 按键 | 浏览 / 弹窗 | 播放 |
|---|---|---|
| 上下左右 | 移动焦点；长正文上下滚动，到边界继续移动 | 显示控件时导航；进度条左右预览 10 秒 |
| 中键 | 确认、播放卡片、切换开关；输入框打开屏幕键盘 | 暂停/继续等当前按钮操作；预览期间确认跳转 |
| 菜单 | 视频卡片上打开详情，其他浏览位置打开设置 | 唤出控件并定位「播放设置」，从按钮进入选集、画质、倍速、队列等 |
| 返回 | 关闭当前层，回到入口；内容逐级返回筛选、子栏、主顶栏；主顶栏返回首页，再次返回退出 | 取消跳转或关闭菜单 → 隐藏控件 → 保存进度并返回浏览 |

控件隐藏时，上键定位播放按钮，下键定位进度条，左右唤出进度条并预览，中键在普通播放状态暂停/继续。直播无进度条，方向操作回到可用按钮。焦点按原有网格和按钮行移动，卡片左右跨行、首尾停止；顶部栏目需中键确认切换，不因移动焦点立即切栏。

浏览内容未到顶部时，上键只操作内容；返回从最近筛选、子栏逐级回到主顶栏。主顶栏左右连通栏目、设置、搜索及账号，纯展示 Logo 不占焦点。搜索可在当前类型刷新，重新请求已缓存的空结果。

播放器菜单、选集和参数面板内的菜单键不会绕过当前层操作后台视频。播放错误可在当前页重试或返回。切集/画质、打开链接和保存等待保留入口与焦点，重复确认仍被门控。没有下一项时跳过禁用按钮。

设置中的选择框和滑条先按中键进入编辑，左右调整，中键或返回结束编辑，上下换行；滚轮仅滚动面板，滑条首次点击只进入编辑。长按仅重复方向键，中键、菜单与返回的长按不会连续确认。Logo、播放器标题/分集来源、详情标题只展示文字，不占导航焦点；完整简介和动态正文仍可聚焦滚动。

屏幕键盘全部操作可通过方向键和中键完成：字母/拼音候选、翻页、中英/数字切换、删除、清空与完成都有按钮。返回先取消待选拼音，再关闭键盘并保留原输入。链接默认英文，搜索默认拼音，词库随包离线提供。

## 当前能力与边界

0.1.9 将同排布行、同方向的弹幕合并为共享动画，并去掉整屏透明度合成；不减少弹幕密度或降低画质。用户已确认多P恢复、《黑袍纠察队 第一季》可搜到；关闭弹幕后电影画面恢复流畅。动态4K/H.264解码失败仍未确认根因，新包的实体电视弹幕效果也仍需复测。隔离1080P样片与密集弹幕能同时持续运行，但模拟器帧率没有稳定改善，不能把图层减少说成整片问题已经解决。

后续用户对照确认：同一失败视频从首页“继续观看”打开仍报MEDIA3。故剩余4K故障随视频/所选轨道出现，不作为动态入口专属错误处理；不能从其他视频的4K成功推断此轨道兼容，也不能在未取得失败视频实际编码参数时声称根因已确定。

0.1.8 在同清晰度内结合当前 WebView MSE 与原生解码器的编码/profile、尺寸、帧率能力选轨，HEVC 须同时通过检查，不自动降画质；MEDIA3/4提示包含实际编码名。切 P、清晰度及重试各使用独立媒体元素和弹幕观察层，旧事件不污染新会话。弹幕合成动画继续滚动，主线程每50ms维护当前条目、每0.5媒体秒检查漂移，暂停/缓冲/跳转立即同步。搜索/影视的验证凭据或缺失列表响应现在明确失败，不冒充“暂无内容”。

用户给出的 BV1Ue4y1w7bk 前三 P 在匿名 Android9/WebView66 下验证实际 H.264/480P 音视频解码、独立 CID、续播与旧元素释放；《黑袍纠察队 第一季》公开搜索也返回对应影视条目。旧0.1.7在同模拟器也能播放这三P，因此尚未复现实体电视的原始失败。此结果不覆盖登录4K、实体电视所有动态或整片弹幕流畅度；设备/内核能力声明也不是实际解码成功。

0.1.7 修复共用路径的三处遗漏：DASH保留平台同轨备用媒体地址，安卓在主节点连接/读取失败时按精确字节续接，不降画质或绕过权限；弹幕仅预排当前时间附近的窗口，滚动由合成线程执行，媒体时钟继续控制暂停、缓冲、倍速及跳转；新关键词及从其他栏目搜索默认查询全部类别，避免漏查影视，同词重复提交保留筛选。播放错误回调现在显示真实MEDIA类别，不再覆盖成通用文字。隔离模拟器及字节夹具通过不代表已经解决实体电视全部动态失败或整片弹幕流畅度问题；实体电视仍需覆盖安装验证。

0.1.6 将普通视频的最新详情和播放签名键读取重叠，之后仍校验所选分集再获取媒体地址；不缓存临时播放地址、不改变默认清晰度。弹幕分批布局并直接按媒体时间绘制当前条目，避免两万条弹幕一次处理和逐帧 React 更新。动态直播通知补齐封面、标题、状态及直播入口，视频筛选仍排除直播通知。播放错误显示有限 MEDIA/DASH 类别或码，版本号来自 manifest，方便实体电视反馈。

相同系统/内核不代表相同硬件解码、内存、DNS/CDN、账号与画质。安卓将10分钟以上视频最高画质预取从引擎默认60秒收至30秒、已播保留从20秒收至10秒，不降画质；这是控制缓冲压力，不是认定内存故障。用户视频 BV1uday6xEW6 在匿名旧内核模拟器可持续解码，不能据此否认实体电视失败，也不能声称“每个普通视频准备慢”和影视搜索为空已找到根因。两小时/两万条合成弹幕回归不等于《让子弹飞》在实体电视整片验收。

0.1.4 修复原生适配的两处实际故障：旧 WebView 重复定位已切片的 DASH Range 导致索引段失败，以及压缩弹幕未经解压被当作 XML。DASH 范围经已注册本机能力传递，媒体保持无账号 Cookie；gzip/raw与zlib DEFLATE 解压后仍受原字节上限约束。第二个匿名公开视频在相同 Android9/WebView66 下持续画面/音频解码、暂停跳转/恢复及3595条弹幕通过。首个公开视频虽然索引读取和177条弹幕已修复，但模拟器后续画面停滞仍未确认原因；不把结果推断为全部视频、音频输出或实体电视已验收。

0.1.3 修复旧 WebView 将拼音候选压缩至10px的问题：待选拼音占独立行，五个候选与翻页分别预留宽度。1920×1080/WebView66 实际候选为95×48px，中键选词通过；现代1920×1080和1440×950也通过。

B 站搜索和二维码请求走原生 HTTPS，使用电视系统证书与 DNS，不能以其他应用能联网推断本应用的具体失败原因。0.1.3 在原错误位置区分域名解析、安全连接、超时与连接失败；安全连接错误检查电视日期时间/系统证书，DNS 错误检查设备解析设置。原始异常、地址及凭证不显示，TLS/主机名验证保持；[系统证书信任默认行为](https://developer.android.com/privacy-and-security/security-config)与[原生连接/读取超时行为](https://developer.android.com/reference/java/net/URLConnection)见 Android 官方说明。

相同内核隔离模拟器的 App/网页二维码生成成功并立即取消、未登录视频搜索24项/番剧搜索21项；测试未扫码或读取日常账号。模拟器会经过电脑的 DNS/代理，其成功不代表实体电视连接已修复，用户当前电视仍报告旧版通用连接错误，需新版具体反馈定位。

| 能力 | 安卓实现 |

## 构建与隔离验证

`YINGJI_ANDROID_SERIAL=emulator-... node scripts/android-media-mirrors-smoke.mjs` 用本机字节夹具核对平台备用媒体的精确读取、无Cookie、权限失败、范围错位及释放取消。`danmaku-renderer-smoke.mjs` 和 `danmaku-motion-smoke.mjs` 可使用同一显式模拟器检查长弹幕池按需布局、合成动画与媒体时钟；不指定模拟器时仅在无窗口现代浏览器中验证。此类夹具不能证明电视CDN、硬件解码或整片流畅度已修复。

播放回归使用显式隔离模拟器：`YINGJI_ANDROID_SERIAL=emulator-... YINGJI_ANDROID_BVID=BV1xx411c7mD YINGJI_ANDROID_EXPECT_FIXED=1 node scripts/android-bilibili-playback-smoke.mjs`，检查匿名实际DASH播放/弹幕、持续视频和音频解码、暂停跳转/恢复及退出，不读取日常凭证。`android-http-body-smoke.mjs` 提供本机压缩/超限/损坏/HEAD及非零Range字节夹具，报告在 `.tmp/android-http-body/`；不把测试输入打包进应用。

`android-bilibili-smoke.mjs` 仅接受显式 `YINGJI_ANDROID_SERIAL=emulator-...`，检查未登录实际视频/番剧搜索、App/网页二维码生成并立即取消，报告不保存二维码或授权数据；设置 `YINGJI_ANDROID_EXPECT_FIXED=1` 同时断言五个候选尺寸与原生中键选词。`android-network-smoke.mjs` 使用 `.tmp/android-network-smoke/self-signed.p12` 临时自签名测试证书（密码fixture），验证原生DNS/证书/连接拒绝/超时和用户取消，不将证书加入系统信任库。所有测试产物留在.tmp，不随APK分发。

需要 Node.js 22.12+、pnpm 11、JDK 17+（本次使用 21）、Android SDK Platform 35 / Build Tools 35.0.0。设置 `ANDROID_HOME`，`JAVA_HOME` 可选；无外部 SDK 时脚本也可使用 `.tmp/android-tools/sdk`。Android SDK 和模拟器为开发工具，不随 APK 分发。

```sh
pnpm package:android
node scripts/renderer-remote-smoke.mjs
```

Windows 使用已安装 Edge 无窗口生成自有电视启动横幅；其他平台需 Playwright Chromium。正常打包关闭 Android/WebView 调试，不包含隔离测试历史或账号。临时构建、截图、样片、SDK 和测试 APK 在 `.tmp/`。

默认签名密钥 `.tmp/android-signing/development.p12` 须保留以便后续覆盖安装。正式签名可设置 `YINGJI_ANDROID_KEYSTORE` 和 `YINGJI_ANDROID_KEYSTORE_PASSWORD` 环境变量，密钥不进入源码、页面或 APK。生成的 `.apk.sha256` 用于校验传输结果。

只有显式设置 `YINGJI_ANDROID_TEST=1` 才会生成可调试的 `.tmp/android-test/` APK，用于新建隔离模拟器。`android-runtime-smoke.mjs` 要求 `YINGJI_ANDROID_SERIAL=emulator-...`，不会自动选择实体电视或读取日常账号。运行前需已安装并启动测试 APK，且 `.tmp/webpage-playback/fixture.mp4` 存在；模拟器访问本机样片服务，不连接真实账号。

WebView 66 使用 `android-legacy-cdp.mjs` 的页级 CDP，现代 Playwright Android 命令在旧内核不可用。`android-legacy-smoke.mjs` 同样仅接受显式隔离模拟器，使用 `.tmp/android-legacy-media/fixture.mp4`（可用 `YINGJI_ANDROID_SAMPLE` 指定测试样片），报告位于 `.tmp/android-legacy-smoke/`。标准 API 兼容库许可随 APK 打包；Zod 未使用的64位边界以 JSBI 精确初始化，IPC 仍仅接受原 JSON 合同，不伪造全局 BigInt 或放宽保护判定。
