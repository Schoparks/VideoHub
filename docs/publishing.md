# 公开仓库维护

README 面向使用者介绍安装、功能和限制；实现细节与测试目录放在开发文档，重要变化记入 CHANGELOG。仓库只提交源码、必要资源、依赖锁文件和文档。

## 不进入 Git 的内容

`.gitignore` 排除依赖、构建输出、本机数据、`.tmp/` 测试产物、浏览器凭证数据库、环境文件、签名私钥、IDE 与代理本机配置。环境模板只有 `.env.example` 或 `.env.*.example` 可提交，其中仍只能包含占位值。

- 账号 Cookie、access token、refresh token、扫码内容及 `account.enc` / `Local State` 不公开。
- 历史、片库、队列、真实账号测试报告、截图及媒体样片保留在本机，不随源码上传。
- APK、Windows 可运行目录及 SDK 不提交到源码仓库；需要分发时单独审核发布产物。
- Android 签名密钥需在仓库外安全备份。默认开发密钥虽位于 `.tmp/`，也不能随清理测试目录一并丢弃。
- 平台客户端公开协议常量与合成测试凭证不等于个人账号凭证，保留原有协议和测试行为；来源说明见 [第三方说明](../THIRD_PARTY_NOTICES.md)。

## 每次提交前

```sh
git status --short
git diff --cached --stat
git diff --cached
git check-ignore .tmp/check.json .env.local private.p12 account.enc
```

核对新增文件内容、文件名、提交作者邮箱及所有暂存改动。扫描 token、私钥、Cookie 和个人绝对路径时只记录命中文件与类别，避免把秘密打印到日志。必要源资源与锁文件不能因批量排除而漏交。

`.gitignore` 只影响未跟踪文件，不能删除已经提交的秘密或历史。若敏感文件已被跟踪，先移出索引并保留本机文件；若凭证曾推送，立即撤销或轮换，再清理历史。不能仅添加忽略规则就视为已消除泄露。

## 报告与截图

问题、评论、截图及 CI 日志同样公开。使用合成数据或空账号复现，删除二维码、个人昵称/头像、私有媒体地址、家庭网络地址和文件路径；账号实测必须事先明确授权，并使用隔离加密副本。完整要求见 [协作规范](../AGENTS.md)。
