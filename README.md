# 映集 · VideoHub

面向「电脑接电视 + 手柄」的聚合播放器，也提供安卓电视七键遥控器版本。将哔哩哔哩、本地片库和 HTTP(S) 媒体放在同一界面，支持续播、分集、混合队列与大屏焦点导航。

桌面版使用 Electron、React 和 TypeScript；安卓电视版使用 WebView 与原生能力桥，复用界面、来源适配和播放会话。

## 功能

- **哔哩哔哩**：扫码授权、推荐、搜索、关注动态、收藏夹、稍后再看、历史、影视与关注直播。推荐行为对照 [BewlyCat](docs/recommendation-parity.md)。
- **本地媒体**：打开文件、导入目录、手动重新扫描，文件保留在原位置。
- **链接播放**：BV 号、B 站视频/影视/直播地址、短链接，以及 HTTP(S) 媒体直链。桌面版还支持视频网页自动检测。
- **播放控制**：分集、清晰度、倍速、全屏、每集独立续播、队列与可选自动连播。音量由系统或电视控制。
- **弹幕**：B 站点播普通滚动、反向、顶部和底部固定弹幕，默认关闭，可调整字号、不透明度与区域。
- **大屏操作**：手柄、键盘、鼠标与安卓遥控器；明暗主题、电视模式、卡片列数、离线拼音屏幕键盘和手柄重映射。
- **手机遥控**：扫码后在手机浏览封面、搜索、选片、修改设置及控制播放；普通 B 站视频显示相关推荐，保留方向/滑动与自定义快捷键。

| 平台 | 运行方式与边界 |
|---|---|
| Windows | 主要桌面验证平台；使用完整 `win-unpacked` 目录运行 |
| macOS / Linux | 提供开发与打包配置，仍需目标系统实机验收 |
| 安卓电视 | Android 9+、Android System WebView 66+；APK 侧载，使用方向、中键、菜单和返回七键 |

当前处于开发阶段。源码仓库不包含构建产物、预装账号或视频资源；本文的 `release/` 路径指本机构建输出。安卓设备能力、安装与限制见 [安卓电视说明](docs/android-tv.md)。

## 从源码运行

需要 **Node.js 22.12+（推荐 24）**、**pnpm 11** 和 Git。项目通过 `packageManager` 固定 pnpm 版本。

```sh
git clone https://github.com/Schoparks/VideoHub.git
cd VideoHub
pnpm install --frozen-lockfile
pnpm exec install-electron --no
pnpm dev
```

Electron 首次运行需要下载对应运行时。`pnpm dev` 同时启动 Vite 与桌面应用；界面支持热更新，修改主进程后需重启。

只查看界面可运行 `pnpm dev:web`。网页预览无法代替桌面或安卓功能验收。

### Windows 可运行目录

```sh
pnpm package:dir
```

运行 `release/win-unpacked/Yingji.exe`。移动或分发时需保留整个 `win-unpacked` 目录及 Electron 附带许可证文件。Windows 始终交付免安装目录，默认打包目标固定为 `dir`。

macOS / Linux 请在对应系统构建；签名、公证和系统依赖需另行配置，构建成功不等于设备兼容性验收。

### 安卓电视 APK

另需 JDK 17+、Android SDK Platform 35、Build Tools 35.0.0，并设置 `ANDROID_HOME`；可通过 `JAVA_HOME` 指定 JDK。Windows 使用已安装 Edge 生成电视横幅，其他平台需先运行 `pnpm exec playwright install chromium`。

```sh
pnpm package:android
```

输出位于 `release/android-tv/`，包含签名 APK 与 SHA-256 校验文件。将 APK 复制到电视后通过文件管理器安装；详细步骤见 [安卓电视说明](docs/android-tv.md)。

自行构建默认生成本机开发签名。密钥必须私下备份，后续覆盖升级需沿用同一密钥；自行构建的包无法直接覆盖其他签名的安装包。正式签名可通过 `YINGJI_ANDROID_KEYSTORE`、`YINGJI_ANDROID_KEYSTORE_PASSWORD` 指定，密钥和密码不得提交到仓库。

## 第一次使用

1. 打开右上角账号入口，选择 **App 推荐授权**，用本人 B 站手机 App 扫码确认。
2. 若 **网页账号授权** 尚未连接，再扫码补充动态、历史、收藏及账号播放权限；两次请使用同一账号。App 授权同时返回网页凭证时会自动保存。
3. 从首页或 B 站栏目选择内容，或使用「打开链接」「打开文件」「本地片库 → 添加目录」。
4. 连接手柄并按键开始操作；标准 Xbox / XInput 映射可直接使用，其他设备可在设置中重映射。电脑接电视时可开启电视模式。

画质、试看和内容可用性取决于账号权限、地区、平台响应及设备解码能力。

在「设置 → 观看」可限制 **B 站清晰度上限**：1080P包含该视频实际提供的1080P、高码率和60帧格式，不把它们视为线性等级。“按分辨率自动选择”在上限内选最高可用分辨率，同分辨率沿服务端顺序；“记住手动选择”优先使用具体档位，缺档回退不覆盖记忆。设置不打断当前播放，下次打开、切集或重新解析时生效，仅作用于B站点播。详见[清晰度说明](docs/bilibili-quality.md)。

## 操作

| 手柄 | 浏览 | 播放 |
|---|---|---|
| 十字键 / 左摇杆 | 移动焦点 | 控件导航；进度条左右预览 10 秒 |
| A | 确认 | 执行操作 / 确认跳转 |
| B | 关闭当前层 / 逐级返回上级栏 | 关闭菜单或取消跳转 → 隐藏控件 → 返回浏览 |
| X | 当前视频详情 | 选集；单集视频定位清晰度 |
| Y | 搜索与屏幕键盘 | 播放队列 |
| LB / RB | 遍历最近栏，边界升到父栏 | 上一集（首集重播） / 下一集或队列下一项 |
| LT / RT | 按屏向上 / 向下浏览 | 向后 / 向前预览 30 秒 |
| Start | — | 播放 / 暂停 |

键盘使用方向键、Enter、Escape、X / Y、PageUp / PageDown；`[` / `]` 在浏览时按屏移动，在播放时预览跳转 30 秒。播放器内空格暂停或继续；菜单与弹窗内空格操作当前控件。Tab / Shift+Tab 移动焦点。

跳转预览须确认才改变播放位置，返回可取消。倍速与清晰度入口确认后打开选择菜单，返回取消。自动连播先处理当前视频的分集，再进入队列下一项。

安卓电视使用方向键移动、中键确认、菜单打开详情或播放设置、返回逐层退出。完整说明见 [七键操作](docs/android-tv.md#七键操作)。

## 手机遥控

电脑或电视启动后手机遥控自动开启，在「设置 → 手机遥控」查看二维码，手机连接同一局域网后扫码。设置按观看、弹幕、手机遥控、手柄分页，两端共用同一套界面。多网卡设备可在「连接地址」中选择手机可达的地址；连不上时检查防火墙的专用网络权限及路由器是否启用了客户端隔离。应用自动重试网络并更新地址，网络地址变化后重新扫码。

手机顶栏与桌面共用首页、哔哩哔哩、关注直播、番剧与影视、本地片库、我的收藏六个栏目及二级分类，窄屏可横向滑动。搜索、历史和工具图标固定，点击打开居中卡片。手机可浏览封面、动态、影视和搜索结果，点选后电视才播放。播放时自动显示图标控制页，可暂停、跳转、切集、调倍速/画质及查看相关推荐；返回首页后，右下角遥控器气泡可恢复控制，切集不强制跳回，滚动后提供返回顶部，没有底栏。历史分为B站历史和本机历史；设置按观看、弹幕、界面切换，无须滚动长列表。手机支持收藏夹浏览与收藏/移除、稍后再看、队列添加/排序/移除。账号仍在电视授权，手机可快速让电视显示登录二维码，不接收扫码数据或平台凭证。链接范围与所在端一致，安卓仍不支持第三方视频网页检测。

遥控使用 HTTP，只用于可信局域网。扫码者可控制应用，勿公开二维码或映射公网端口。应用保持运行时连接持续有效，手机关闭标签页后重访同一地址可自动重连；可在手机设置中忘记连接。切出安卓应用期间不执行指令，返回后沿用原连接；退出或系统结束进程后，再启动需扫码。手机保存快捷键与配对密钥，只接收列表显示信息，不接收账号凭据、本地文件路径或媒体地址。浏览器界面预览不提供此能力。

## 隐私与数据

- 授权由本人扫码取得；桌面凭证通过系统安全存储保护，安卓通过 Keystore 加密。安全存储不可用时仅保留在会话内存，不以明文替代。
- 本地导入不移动或上传媒体文件；片库、队列、偏好与续播记录保存在本机。B 站历史回写可在设置中控制。
- 平台凭证仅用于受信平台接口，不发送给封面、媒体 CDN 或用户提供的直链主机。
- 桌面视频网页检测使用隔离临时会话，不共享 B 站账号；屏幕键盘词库离线提供。
- 提交问题前请删除 Cookie、token、二维码、签名媒体链接和私人文件路径。仓库忽略规则与公开前检查见 [公开仓库维护](docs/publishing.md)。

## 已知限制

- 安卓版尚未移植第三方视频网页自动检测；桌面检测也不保证兼容登录、验证码、广告或所有多视频页面。
- 播放依赖 Chromium / WebView 和设备解码器，不承诺任意 MKV / AVI 内部编码、HEVC、杜比、HDR 或内嵌 ASS 字幕兼容；未集成转码、字幕轨管理及音频设备选择。
- 不提供 DRM 解密或付费、地域限制绕过。只能播放平台允许且可确认未加密的媒体；兼容格式可能受画质和试看限制。
- 本地目录需手动重新扫描；没有文件监控、文件移动自动匹配或 NAS 凭证管理。
- 非官方 B 站接口可能变化。实体设备的编码、音频输出与长时间播放仍需分别验证，旧电视部分 4K 解码和弹幕性能问题仍待实机复测。
